# 📸 Photo Editor

A modern, feature-rich photo editing website built with vanilla HTML, CSS, and JavaScript. Edit and enhance your photos directly in your browser with no installations required!

## Features

✨ **Image Adjustments**
- Brightness control
- Contrast adjustment
- Saturation control
- Hue rotation
- Blur effect
- Grayscale filter
- Sepia tone
- Invert colors

🎨 **Presets**
- Vintage filter
- Cool tone preset
- Warm tone preset
- Black & White preset

⬇️ **Export Options**
- Download edited images as PNG
- Copy edited images to clipboard

🎯 **User-Friendly Interface**
- Real-time preview of changes
- Responsive design (desktop, tablet, mobile)
- Beautiful gradient UI with smooth animations
- Intuitive slider controls with value display

## How to Use

1. **Open the Website**: Open `index.html` in your web browser
2. **Upload an Image**: Click the file input or drag & drop an image
3. **Edit Your Photo**: Use the sliders to adjust various filters and effects
4. **Apply Presets**: Click preset buttons for quick styling (Vintage, Cool, Warm, B&W)
5. **Download or Copy**: Save your edited image or copy it to clipboard

## Features in Detail

### Image Adjustments
Each adjustment is controlled by a slider with real-time preview:
- **Brightness** (0-200%): Make the image lighter or darker
- **Contrast** (0-200%): Increase or decrease the difference between light and dark areas
- **Saturation** (0-200%): Control the intensity of colors
- **Hue Rotation** (0-360°): Shift colors around the color wheel
- **Blur** (0-20px): Apply blur effect to the entire image
- **Grayscale** (0-100%): Convert to black and white
- **Sepia** (0-100%): Apply vintage brown tone
- **Invert** (0-100%): Invert all colors

### Preset Filters
Quick-apply combinations of filters:
- **Vintage**: Reduced contrast, sepia tone, lower saturation
- **Cool**: Increased contrast, boosted saturation, hue shifted to blue
- **Warm**: Increased brightness, boosted saturation, hue shifted to orange
- **B&W**: Full grayscale with increased contrast

### Export Options
- **Download**: Saves the edited image as PNG file with timestamp
- **Copy**: Copies the edited image to clipboard for easy pasting

## Tips & Tricks

1. **Fine-tuning**: Make small adjustments to get the perfect look
2. **Combining filters**: Mix and match filters for unique effects
3. **Undo**: Simply adjust the slider back or click Reset
4. **Mobile friendly**: Works great on touch devices
